⚙️ 알람 연동 설정 방법
  1. 시리 단축어 만들기: 단축어 앱 → 단축어 탭 → + → 이름을 모닝브리핑으로 지정
  2. 동작 추가: URL의 콘텐츠 가져오기 → URL에 아래 주소 붙여넣기

  3. 동작 추가: 텍스트 말하기 (언어 한국어, 음성은 시리)
  4. 알람 연동: 자동화 탭 → + → 알람 → 중단됨 → 즉시 실행 → 동작에서 단축어 실행 → 모닝브리핑 선택
  5. 이 앱을 홈 화면에: 사파리 공유 버튼 → 홈 화면에 추가
